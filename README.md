# /dev/null

Omarchy theme mirroring [dev-null.sh](https://dev-null.sh) dark mode: graphite shell, Commit Blue accent, author-lane ANSI colors.

## Install

```bash
omarchy theme install <this-repo-url>
omarchy theme set "Dev Null"
```

Or link a local checkout:

```bash
ln -sfn "$(pwd)" ~/.config/omarchy/themes/dev-null
omarchy theme set "Dev Null"
```
